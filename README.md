# 락토코리아 바이어 데스크

해외 전시회(SIAL Paris 2026 등)에서 만난 바이어의 상담 기록, 주소록, 팔로우업을 팀이 함께 관리하는 사이트입니다.
구글 계정 하나로 운영되고, 팀원은 사이트 주소와 접속 코드만 있으면 됩니다.

- 사이트: https://psl212158.github.io/lacto-buyer-desk/
- 화면: GitHub Pages (`index.html`)
- 데이터: 구글 시트 + Apps Script (`apps-script/Code.gs`)
- 명함 자동 인식: 구글 드라이브 글자 인식(OCR). 별도 API 키나 비용이 없습니다
- 상담 사진(명함, 바이어와 함께 찍은 사진 등): 구글 드라이브 폴더

이 저장소에는 바이어 데이터가 들어 있지 않습니다. 데이터는 구글 시트와 드라이브에만 저장되고, 사이트는 팀 접속 코드를 아는 사람만 열 수 있습니다.

## 처음 설정 (관리자 한 명이 한 번만)

1. 구글 드라이브에서 새 스프레드시트를 만듭니다 (https://sheets.new).
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 코드를 지우고 [`apps-script/Code.gs`](https://raw.githubusercontent.com/psl212158/lacto-buyer-desk/main/apps-script/Code.gs) 전체를 붙여 넣은 뒤 저장합니다.
4. 위쪽 함수 목록에서 `setup`을 고르고 **▶ 실행**을 누릅니다.
   - 권한 요청이 나오면 본인 계정 → "Google에서 확인하지 않은 앱" 화면에서 **고급 → (프로젝트)(으)로 이동 → 허용**.
   - 시트에 '시작하기' 탭이 생기고 **팀 접속 코드**가 자동으로 만들어져 적힙니다.
5. 오른쪽 위 **배포 → 새 배포 → 유형 선택(톱니바퀴) → 웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - **배포**를 누르고 나오는 웹 앱 URL(`https://script.google.com/macros/s/…/exec`)을 복사합니다.
6. 사이트에서 서버 주소(5번 URL), 접속 코드('시작하기' 탭), 이름을 입력하고 입장합니다.

`config.js`의 `apiUrl`에 5번 URL을 넣어 두면 팀원 로그인 화면에서 서버 주소 칸이 사라지고, 접속 코드와 이름만 입력하면 됩니다.

## 접속 코드 바꾸기

시트의 '시작하기' 탭에서 접속 코드 칸을 고친 뒤, 시트 메뉴 **바이어 데스크 → 초기 설정 · 접속 코드 반영**을 누릅니다.
바뀐 뒤에는 팀원 모두 새 코드로 다시 로그인합니다.

## 코드를 고친 뒤

- `index.html`, `config.js`: 사이트는 `gh-pages` 브랜치에서 배포됩니다. `main`에 커밋한 뒤 같은 내용을 `gh-pages`에도 푸시하면(`git push origin main main:gh-pages`) 1~2분 뒤 바뀝니다.
  `main` 하나로만 관리하려면 **Settings → Pages**에서 Branch를 **main / (root)**로 바꾸면 됩니다.
- `Code.gs`: Apps Script에 다시 붙여 넣고 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 누릅니다. 웹 앱 URL은 그대로 유지됩니다.
  - 지금 운영 중인 서버는 [clasp](https://github.com/google/clasp)로 올렸습니다. `.clasp.json`이 있는 PC에서는 `clasp push` 후 `clasp redeploy <배포 id>`로 같은 URL에 새 버전을 올릴 수 있습니다(배포 id는 `config.js` 주소의 `/s/`와 `/exec` 사이).
  - 웹 앱 설정(실행: 나 / 액세스: 모든 사용자)은 `apps-script/appsscript.json`에 들어 있습니다.
  - 처음 배포한 뒤 소유자가 권한을 허용해도, 몇 분 동안은 403이 날 수 있습니다. setup을 따로 안 돌렸으면 웹 앱 주소를 처음 열 때 자동으로 실행됩니다.

## 데이터 구조

| 시트 탭 | 내용 |
|---|---|
| 시작하기 | 사이트 주소, 팀 접속 코드, 설정 안내 |
| 바이어 리스트 | 사람이 보는 표. 10분마다, 또는 메뉴 **바이어 데스크 → 바이어 리스트 새로고침**으로 갱신 |
| shows | 참가 전시회 (이름, 장소, 기간, 부스) |
| buyers | 바이어 회사·담당자, 등급, 진행 단계, 다음 액션 |
| meetings | 상담 기록 (일자, 관심 제품, 요청사항, 메모, 사진 목록) |
| followups | 팔로우업 기록 (연락 방식, 내용, 바이어 반응, 다음 액션) |

shows / buyers / meetings / followups 탭은 사이트가 읽고 쓰는 원본이라 직접 고치지 마세요.

## 명함 자동 인식

명함 사진을 구글 드라이브가 문서로 변환하면서 글자를 읽고(OCR), 서버가 그 글자에서 회사명·이름·직책·이메일·전화·웹사이트·국가·도시를 골라 입력 칸에 채웁니다.
자동으로 채운 칸은 파란색으로 표시되니 저장 전에 확인하세요. 이메일·전화·웹사이트는 정확도가 높고, 이름·회사명·직책은 명함 디자인에 따라 고쳐야 할 때가 있습니다.
